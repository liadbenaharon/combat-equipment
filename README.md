# combat-equipment

אפליקציית ווב Mobile-First בעברית לניהול ומעקב אחר ציוד באימוני כושר קרבי.

## תכונות
- צ׳ק-ליסט ציוד עם סימון נפרד לכל יחידה
- שיוך ציוד למתאמנים לפי שם וכמות
- סיכום מי סוחב מה
- היסטוריית אימונים לפי תאריך
- הוספת ציוד מותאם אישית
- שמירה מקומית בדפדפן באמצעות localStorage
- ממשק RTL בעיצוב טקטי כהה

האפליקציה נמצאת בקובץ `index.html` וניתנת לפרסום ישירות באמצעות GitHub Pages.

## v1.3.7 — אנשי קשר ל־WhatsApp

במסך **נוכחות**, פתחו **אנשי קשר ל־WhatsApp** להוספה, עריכה ומחיקה של שם, מספר ושמות חלופיים. אפשר לייבא בהדבקה שורה לכל איש קשר: `שם,מספר,כינוי ראשון|כינוי שני`. נתמכים גם עמודות מגיליון (Tab), נקודה־פסיק ושורת כותרת `שם,מספר,שמות חלופיים`.

מספר ישראלי מקומי מומר לקידומת 972; במספר מחו״ל יש לכלול קידומת מדינה. ייבוא חוזר של שם ראשי זהה מעדכן את המספר ואת הכינויים שלו. שורה שגויה או התנגשות בין שמות/כינויים מבטלת את הייבוא כולו בלי לשנות את הרשימה השמורה.

הנתונים נשמרים רק ב־localStorage של אותו דפדפן ומכשיר, בנפרד מציוד ומהיסטוריית אימונים. מספרים מהגרסה הקודמת נשארים זמינים ומועברים לפורמט החדש בשמירה הראשונה. אין סנכרון אנשי קשר לשרת. ניקוי נתוני הדפדפן מוחק את אנשי הקשר.

כשאדם מסומן כלא מגיע ויש לו ציוד, כפתור WhatsApp פותח צ׳אט ישיר אם נמצאה התאמה יחידה לשם או לכינוי. אחרת נפתחת בחירת איש קשר ב־WhatsApp. ההודעה מוכנה לשליחה ידנית; כפתור **העתק הודעה** נשאר זמין. המספר וההודעה מועברים ל־WhatsApp רק בלחיצה על הכפתור.
