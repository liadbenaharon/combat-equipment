# טיוטת Data Safety

המסמך מתאר את הבנייה הנוכחית בלבד. יש להשוות אותו ל־AAB הסופי ולדוח ההרשאות לפני הגשה.

## סיכום התנהגות

- שמות, ציוד, נוכחות, מספרי טלפון והיסטוריה נשמרים מקומית באחסון הדפדפן במכשיר.
- אין שרת אפליקציה, חשבון, analytics, פרסום, Firebase או SDK לאיסוף מידע.
- מעטפת Android מבקשת רק `INTERNET`, חוסמת HTTP לא מוצפן ואינה מבקשת אנשי קשר, מיקום, מצלמה, מיקרופון, קבצים או התראות.
- לחיצה יזומה על WhatsApp מעבירה ל־WhatsApp מספר והודעה שהמשתמש בחר לפתוח. האפליקציה אינה שולחת את ההודעה בעצמה.
- Android Browser Helper מעביר לדפדפן המארח את כתובות ה־URL שהאפליקציה פותחת כדי להציג את ה־TWA.

## תשובות שמרניות מוצעות

| שאלה | תשובה מוצעת | הערה |
|---|---|---|
| האם האפליקציה אוספת או משתפת נתוני משתמש? | כן | בגלל העברת URL לדפדפן המארח; אין איסוף לשרת של המפתח |
| סוג הנתון | Web browsing | ה־URL המטופל על ידי מעטפת ה־TWA |
| נאסף או משותף? | משותף | מועבר מקומית לאפליקציית הדפדפן |
| מטרה | App functionality | נדרש לפתיחת תוכן האפליקציה |
| חובה או אופציונלי? | חובה | ללא פתיחת ה־URL אין TWA |
| מוצפן בתעבורה? | כן | כתובת האתר היא HTTPS בלבד ו־cleartext חסום |
| חשבון משתמש | אין | אין הרשמה או התחברות |
| בקשת מחיקת חשבון | לא חל | אין חשבונות ואין נתונים בשרת המפתח |
| פרסומות | לא | אין SDK או תוכן פרסומי |

הנתונים המעובדים רק במכשיר אינם נחשבים „נאספים” לפי הגדרת Google Play. העברה ל־WhatsApp נעשית בעקבות פעולה מפורשת וצפויה של המשתמש; יש לאמת במסך ההצהרה הסופי אם היא נכנסת לחריג של user-initiated action עבור הבנייה שנבדקה.

## בדיקה לפני שליחה

1. לבדוק את רשימת ההרשאות של ה־AAB הסופי ב־App Bundle Explorer.
2. לוודא שלא נוספו analytics, crash reporting, ads או SDK נוספים.
3. להשוות את ההצהרה למדיניות הפרטיות הציבורית.
4. לשמור צילום/ייצוא של הטופס שהוגש עם מספר הגרסה.
